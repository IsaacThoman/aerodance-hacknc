# MediaPipe pose assets

Runtime source and license: https://github.com/google-ai-edge/mediapipe
License text: https://www.apache.org/licenses/LICENSE-2.0

Pose Landmarker Lite, Full, and Heavy float16 version 1 bundles come from Google's
MediaPipe model distribution. Model documentation and model card:
https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker#models
https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf

The application pins model sizes and SHA-256 checksums in models.js. The build
copies these notices with the locally served models and WASM runtime.
